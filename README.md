# ☢️ Helwan Mines Pro

**The Ultimate Memory & Speed Challenge for Helwan Linux!**

Welcome to a professional reimagining of the classic Minesweeper. **Helwan Mines Pro** isn't just about logic; it’s a high-stakes test of your memory, speed, and mental sharpness.

---

## ✨ What Makes This Version Unique?

* ⚡ **Data Decay Mechanic:** Revealed numbers are not permanent! They fade away after 5 seconds, turning into dots. You must memorize the board to survive.

* ⏲️ **Time Pressure:** You have a strict 60-second countdown to clear the entire field. Can you beat the clock before the big explosion?

* 🎨 **Helwan Native Design:** Featuring a clean, Nordic-inspired UI that integrates perfectly with the Helwan Linux ecosystem.

* 🧠 **Mental Workout:** This game transforms simple logic into a dynamic "brain sport" by forcing you to manage shifting information.

---

## 🎮 How to Play

* **The Objective:** Reveal all safe cells and avoid clicking on the hidden mines (☢️).

* **Memorize Quickly:** Once a number appears, commit it to memory instantly. In 5 seconds, it will disappear, leaving you with only your instincts.

* **Use the Interface:** Access the Game and Help menus for manual instructions, restarting, or exiting the application.

---

## 📥 Installation (For Helwan Linux Users)

The easiest way to get the game is via the official package manager:

```bash
sudo pacman -S hel-mines
```

(Alternatively, you can clone the repository and build the PKGBUILD manually if you are an advanced user).
